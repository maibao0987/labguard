# IDOR：其他成員的私人任務可被讀取

- 分類：CWE-639。
- 前置條件：本人本機 TaskBoard，Alice 與 Bob 的虛構種子資料。
- 根因：`labguard/taskboard.py` 在 vulnerable 模式跳過任務物件權限檢查；只要知道 ID 就可讀取。

## 本機重現

1. 在 :5101 使用 Alice 登入，查看自己的 /tasks/1。
2. 手動改為 /tasks/2，觀察 Bob 私人任務與 BOB-PRIVATE-SEED。
3. 在 :5102 修復版以 Alice 存取相同路徑，應回傳 403。
4. Bob 仍可讀取自己的任務；管理員可讀取全部；所有成員可讀團隊任務 3。

## 修復

每次讀寫任務時驗證：擁有者為本人、任務為團隊共享、或具有管理員角色。不能只在列表隱藏資料，也不能把難猜 ID 當成授權機制。

## 驗收

權限矩陣同時涵蓋允許及拒絕。修復原資產後才能關閉原弱點；對 asset #2 的成功檢查不能代替 asset #1 複測。網路錯誤、登入失敗或非預期狀態碼均視為無法判定。
